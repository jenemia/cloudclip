CloudClip이란?

CloudClip은 스마트폰과 PC 사이에서 텍스트와 사진을 바로 옮기는 무료 웹 클립보드입니다. 아이폰·안드로이드에서 복사한 내용을 맥·윈도우 브라우저로, 또는 그 반대로 옮길 때 카카오톡 ‘나에게 보내기’나 메일 없이 붙여넣기 한 번으로 끝납니다. 앱 설치·회원가입·로그인이 필요 없고, 올린 내용은 1시간 뒤 자동 삭제됩니다.

사용 방법 (30초)

  1. 붙여넣기 — 폰에서 텍스트나 사진을 복사하고 이 페이지에 붙여넣습니다. 필요하면 4자리 비밀번호를 정합니다.
  2. 링크 만들기 — ‘공유 링크 만들기’를 누르면 cloudclip/ab3k9xyz 같은 고유 주소와 8자리 코드가 생깁니다.
  3. 다른 기기에서 열기 — PC 브라우저에서 주소로 들어가거나 메인 화면에 코드를 입력하고 ‘복사’를 누릅니다.

특징

  • 설치·로그인 없음 — 웹 브라우저만 있으면 iOS, Android, macOS, Windows 어디서나.
  • 텍스트 + 사진 — 여러 장의 이미지도 한 번에. 받는 쪽에서 원클릭 복사·저장.
  • 1시간 후 자동 삭제 — 남은 시간이 표시되고, ‘지금 삭제’로 즉시 지울 수 있습니다.
  • 추측하기 어려운 주소 — 클립마다 무작위 8자리 주소. 목록 페이지가 없고 검색엔진에 노출되지 않습니다.
  • 4자리 비밀번호 — 5번 틀리면 클립이 바로 삭제됩니다.
  • 📌 고정 페이지 + QR 코드 — 주소가 바뀌지 않는 나만의 페이지에서 폰·PC가 계속 주고받을 수 있습니다. QR로 바로 열고, 마지막 사용 6시간 뒤 자동 삭제.
  • 무료 — 광고 없는 단순한 도구.

자주 묻는 질문

아이폰에서 복사한 텍스트를 윈도우 PC로 옮기려면?

아이폰 브라우저에서 CloudClip에 접속해 붙여넣고 ‘공유 링크 만들기’를 누른 뒤, PC 브라우저에서 생성된 주소(또는 8자리 코드)로 열어 ‘복사’를 누르면 됩니다.

회원가입이나 앱 설치가 필요한가요?

아니요. 웹 브라우저만 있으면 되고 계정이 필요 없습니다.

올린 내용은 언제 삭제되나요?

1시간이 지나면 서버에서 자동으로 삭제됩니다. ‘지금 삭제’ 버튼으로 바로 지울 수도 있습니다.

다른 사람이 내 클립을 볼 수 있나요?

클립마다 추측하기 어려운 무작위 주소가 발급되고 목록이 없습니다. 비밀번호를 걸면 비밀번호를 아는 사람만 볼 수 있고, 5번 틀리면 즉시 삭제됩니다.

사진도 옮길 수 있나요?

네. 여러 장을 한 번에 올릴 수 있고(합계 약 14MB), 받는 쪽에서 이미지 복사나 파일 저장이 가능합니다.

PC에서 스마트폰으로도 보낼 수 있나요?

네. 방향과 관계없이 어느 기기에서든 붙여넣고 다른 기기에서 열면 됩니다.

매번 링크를 새로 만들지 않고 같은 주소를 쓸 수 있나요?

네. ‘고정 페이지’를 만들면 주소가 바뀌지 않는 나만의 페이지가 생기고, QR 코드로 다른 기기에서 바로 열 수 있습니다. 비밀번호가 항상 필요하며, 마지막 클립이 도착한 뒤 6시간이 지나면 삭제됩니다.

요금이 있나요?

무료입니다.
